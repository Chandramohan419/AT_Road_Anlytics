# AT_Road_Anlytics
Built an end-to-end data engineering solution using Python, Snowflake, dbt, and Power BI. The project ingests Auckland Transport roadworks data, applies data quality testing and dimensional modeling using dbt, and delivers interactive dashboards for tracking project status, duration, contractor performance, and overdue roadworks with location.

# Tech Stack
Python
Snowflake
dbt
Power BI
GitHub

# Features
Automated data ingestion
Snowflake data warehouse
dbt staging, intermediate, and mart layers
Data quality tests
Incremental models
Snapshots for change tracking
Star schema design
Interactive Power BI dashboards

# Architecture
Auckland Transport API → Python Ingestion → Snowflake (Raw) → dbt Transformations → Power BI Dashboards
